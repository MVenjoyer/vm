# Виртуальная машина

## Описание проекта

Реализация виртуальной машины на Python для исполнения Python-байткода. Проект представляет собой учебный интерпретатор
с полным циклом выполнения байткода. К сожалению vm реализует не все инструкции, а какие именно вы можете узнать из тестов.

Это "pet" - проект, так что не содержит никакого cli и тд

Но вы можете запустить тесты

Для этого:

```bash
pip install -r requirements.txt
```

А затем

```
pytest
```
