# Виртуальная машина

## Описание проекта

Реализация виртуальной машины на Python для исполнения Python-байткода. Проект представляет собой учебный интерпретатор
с полным циклом выполнения байткода. К сожалению vm реализует не все инструкции, а какие именно вы можете узнать из
тестов.

Для запуска vm, вам достаточно выполнить команду:

```bash
    python main.go <path_to_your_file_with_py_code>
```

Так же вы можете запустить тесты

Для этого:

```bash
pip install -r requirements.txt
```

А затем

```
pytest
```
